# Knowledge-Distillation-of-Large-Language-Models-for-Efficient-Text-Generation--GPT-
Hybrid Knowledge Distillation for efficient text generation using GPT-2 Large as teacher and GPT-2 Small as student. Combines Cross-Entropy and KL-Divergence losses with temperature scaling, trained on WikiText-103 and OpenWebText. Achieved 36.20 perplexity and 6.6× model compression.
